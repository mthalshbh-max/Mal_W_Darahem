# مال ودراهم — Flutter v2.0.0

نسخة مشروع Flutter قابلة للفتح والتعديل.

## المزايا الحالية
- لوحة ملخص للرصيد والدخل والمصروفات.
- إضافة معاملات دخل أو مصروف.
- سجل المعاملات.
- قسم الديون مع اسم الشخص والمبلغ وتاريخ الاستحقاق.
- أهداف الادخار.
- اختيار العملة.
- حفظ البيانات محليًا على الجهاز.
- واجهة عربية RTL.
- وضع داكن.

## التشغيل
1. ثبّت Flutter وAndroid Studio/Android SDK.
2. افتح هذا المجلد في Android Studio أو VS Code.
3. نفّذ:
   flutter pub get
4. للتجربة:
   flutter run
5. لبناء APK:
   flutter build apk --release

> هذه حزمة مصدر Flutter وليست APK جاهزًا. يجب بناء APK واختباره على جهاز أندرويد قبل اعتباره إصدارًا نهائيًا للنشر.
